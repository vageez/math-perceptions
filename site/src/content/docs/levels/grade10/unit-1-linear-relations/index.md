> **Big idea:** A straight line shows how one quantity changes as another changes.

## Start with the picture

```text
coordinates        slope          line equation       two lines
  (x, y)     →    rise/run    →     y = mx + b    →   intersection
where is it?      how steep?       which line?         where meet?
```

If you can answer those four questions, most Unit 1 questions become familiar instead of surprising.

## The recognition map

| When you see… | Think… | First move |
|---|---|---|
| `(x, y)` | Coordinates | Across with `x`, then up/down with `y` |
| Two points | Slope | Use the slope formula |
| `y = mx + b` | Line equation | Read `m` and `b` |
| Same slope | Parallel lines | Compare y-intercepts |
| Negative reciprocal slopes | Perpendicular lines | Flip the fraction and change the sign |
| Two equations | System | Choose graphing, comparison/substitution, or elimination |

## Unit goal

By the end of Unit 1, I can:

- [ ] plot and read coordinates;
- [ ] calculate and interpret slope;
- [ ] write and graph `y = mx + b`;
- [ ] find x- and y-intercepts;
- [ ] recognize horizontal, vertical, parallel, and perpendicular lines;
- [ ] solve a system by graphing, comparison/substitution, and elimination;
- [ ] check whether my answer makes sense.
