> **Plain language first. Use the linked page when you need the full picture.**

| Term | Plain-language meaning | Formal meaning / clue |
|---|---|---|
| Cartesian plane | A map for locating points | Two perpendicular number lines: x-axis and y-axis |
| coefficient | A number multiplying a variable | In `3x`, the coefficient is `3` |
| comparison method | Set two equal expressions equal to each other | Often used when both equations equal `y` |
| dependent variable | The result that responds | Usually plotted on the y-axis |
| elimination | Cancel one unknown to solve for the other | Add or subtract equations |
| equation | A statement that two expressions are equal | Contains an equals sign |
| horizontal line | A flat line | `y = c`; slope `0` |
| independent variable | The input or quantity changed first | Usually plotted on the x-axis |
| intercept | Where a line crosses an axis | x-intercept or y-intercept |
| linear relation | A relationship with a constant rate of change | Its graph is a straight line |
| negative reciprocal | Flip a fraction and change its sign | Used for perpendicular slopes |
| ordered pair | The address of a point | Written `(x, y)` |
| origin | The centre of the coordinate plane | `(0, 0)` |
| parallel lines | Lines that travel in the same direction and never meet | Same slope; distinct lines have different intercepts |
| perpendicular lines | Lines that meet at a square corner | Meet at `90°`; slopes are negative reciprocals |
| quadrant | One of four regions of the coordinate plane | Numbered I–IV counterclockwise |
| rate of change | How much one quantity changes compared with another | For a line, this is slope |
| rise | Vertical change | `y₂ − y₁` |
| run | Horizontal change | `x₂ − x₁` |
| slope | A line’s steepness and direction | `rise/run`, represented by `m` |
| slope-intercept form | A line written to show its slope and starting height | `y = mx + b` |
| solution of a system | Values that make both equations true | The intersection `(x, y)` |
| standard form | A line written as `Ax + By = C` | Rearrange to `y = mx + b` to read the slope |
| substitution | Replace a variable with an equal expression | A method for solving a system |
| system of equations | Two equations solved together | Usually asks for a shared solution |
| variable | A symbol for a value that can change | Often `x` or `y` |
| vertical line | A straight up-and-down line | `x = c`; slope undefined |
| x-axis | Horizontal axis | Points on it have `y = 0` |
| x-intercept | Where a line crosses the x-axis | Set `y = 0`; point `(x, 0)` |
| y-axis | Vertical axis | Points on it have `x = 0` |
| y-intercept | Where a line crosses the y-axis | Set `x = 0`; point `(0, y)`; `b` in `y = mx + b` |

## Symbol decoder

| Symbol | Read it as |
|---|---|
| `(x, y)` | a point with x-coordinate then y-coordinate |
| `m` | slope |
| `b` | y-intercept in `y = mx + b` |
| `m₁`, `m₂` | slopes of line 1 and line 2 |
| `Δ` | “change in” |
