> **Question:** How do I read, write, and graph a straight line?

## Think of a starting point and a movement rule

`b` tells you where to start on the y-axis. `m` tells you how to move from there.

<CoordinatePlane mode="line" start={[[0, -1], [2, 3]]} labels={['A', 'B']} />

**Drag either point.** The equation rewrites itself, and the hollow dot marks `b` — where the line crosses the y-axis.

## Worked example

**Write the equation of the line with slope $3$ and y-intercept $-2$.**

1. Start from slope-intercept form: $y = mx + b$.
2. The slope is $m$, so $m = 3$.
3. The y-intercept is $b$, so $b = -2$.
4. Substitute both: $y = 3x + (-2)$.
5. Adding a negative is the same as subtracting: $y = 3x - 2$.

**Answer:** $y = 3x - 2$.

## Slope-intercept form

$$
y=mx+b
$$

- `m` = slope or rate of change
- `b` = y-intercept, the y-value where `x = 0`

Some resources use `y = ax + b`; in that notation, `a` is the slope.

## Formal meaning

A linear equation describes every point on a straight line. In slope-intercept form, its slope and y-intercept are visible immediately.

## Read an equation

For `y = −3x + 5`:

- slope: `m = −3 = −3/1`;
- y-intercept: `b = 5`, so the line crosses at `(0, 5)`;
- the line falls 3 units for every 1 unit moved right.

Watch hidden values:

| Equation | m | b |
|---|---:|---:|
| `y = x + 4` | 1 | 4 |
| `y = −x − 2` | −1 | −2 |
| `y = 6x` | 6 | 0 |

## Graph from an equation

Graph `y = 1/2 x − 3`:

1. Plot the y-intercept `(0, −3)`.
2. Read `m = 1/2` as rise `1`, run `2`.
3. From `(0, −3)`, move up 1 and right 2. Plot the next point.
4. Repeat or move down 1 and left 2.
5. Draw a straight line through the points with arrows.

## Write an equation from a graph

1. Read the y-intercept `b`.
2. Choose two exact points and calculate slope `m`.
3. Substitute both into `y = mx + b`.
4. Check another point from the graph.

## Write an equation from a slope and one point

The line has slope `3` and passes through `(2, 7)`.

Substitute `m = 3`, `x = 2`, and `y = 7`:

$$
7=3(2)+b
$$

$$
7=6+b \quad\Rightarrow\quad b=1
$$

Therefore:

$$
y=3x+1
$$

## Write an equation from two points

Given `(1, 4)` and `(5, 12)`:

1. Find slope: `m = (12 − 4)/(5 − 1) = 2`.
2. Use either point: `4 = 2(1) + b`, so `b = 2`.
3. Write the equation: `y = 2x + 2`.
4. Check the second point: `12 = 2(5) + 2` ✓

## More worked examples

### Example 2 — From a slope and one point

**Write the equation of the line with slope $-\tfrac{3}{2}$ that passes through $(2,\ 1)$.**

1. Start from $y = mx + b$ and put in the slope: $y = -\tfrac{3}{2}x + b$.
2. The line passes through $(2,\ 1)$, so $x = 2$ and $y = 1$ must fit: $1 = -\tfrac{3}{2}(2) + b$.
3. Work out the product: $-\tfrac{3}{2}(2) = -3$, so $1 = -3 + b$.
4. Add $3$ to both sides: $b = 4$.
5. Put $m$ and $b$ back into the form.

**Answer:** $y = -\tfrac{3}{2}x + 4$. Check: at $x = 2$, $-3 + 4 = 1$. ✓

### Example 3 — A line with no $y = mx + b$ form

**Write the equation of the line through $(4,\ 1)$ and $(4,\ -6)$.**

1. Find the slope first: $m = \dfrac{-6 - 1}{4 - 4} = \dfrac{-7}{0}$.
2. Dividing by $0$ has no value, so the slope is undefined.
3. An undefined slope means the line is vertical, and a vertical line cannot be written as $y = mx + b$.
4. Look at what both points share: each has $x = 4$.
5. A vertical line is written as x equals a number.

**Answer:** $x = 4$. Writing "$y = $" anything here would be wrong.

## When you see… think…

| When you see… | Think… |
|---|---|
| `y = mx + b` | Read slope and y-intercept |
| Need to graph an equation | Start at `b`, then use `m` |
| Slope plus one point | Substitute to find `b` |
| Two points | Find `m`, then find `b` |
| Table of values | Find constant change or substitute x-values |

## Common exam mistakes

- Calling `b` the x-intercept; it is the **y-intercept**.
- Plotting `b` on the x-axis.
- Reading `m = 2` as rise 1, run 2 instead of `2/1`.
- Forgetting that `y = x + 4` has slope 1.
- Finding slope but stopping before writing the full equation.
- Drawing a line segment without extending it.

## Quick check

1. State the slope and y-intercept of `y = −2x + 7`.
2. Write the equation of a line with slope `1/2` and y-intercept `−4`.
3. Write the equation of the line through `(0, 3)` and `(2, 7)`.

<details>
<summary>Answers</summary>

**1. Slope and y-intercept of $y = -2x + 7$**

1. Compare with $y = mx + b$.
2. The number multiplying $x$ is $m$, so $m = -2$.
3. The number on its own is $b$, so $b = 7$.

**Answer:** $m = -2$; the y-intercept is $(0,\ 7)$.

**2. Line with slope $\tfrac{1}{2}$ and y-intercept $-4$**

1. Start from $y = mx + b$.
2. Put in $m = \tfrac{1}{2}$ and $b = -4$.
3. Adding a negative becomes subtracting.

**Answer:** $y = \tfrac{1}{2}x - 4$.

**3. Line through $(0,\ 3)$ and $(2,\ 7)$**

1. Slope: $m = \dfrac{7 - 3}{2 - 0} = \dfrac{4}{2} = 2$.
2. The point $(0,\ 3)$ has $x = 0$, so it *is* the y-intercept: $b = 3$.
3. Substitute both into $y = mx + b$.

**Answer:** $y = 2x + 3$.
