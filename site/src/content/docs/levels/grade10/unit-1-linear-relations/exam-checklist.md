> Tick a box only after you can do it **without notes**.

## 1. Coordinates

- [ ] I write points in `(x, y)` order.
- [ ] I plot and read points in all four quadrants.
- [ ] I identify points on the axes and at the origin.
- [ ] I turn a table of values into ordered pairs.
- [ ] I identify independent and dependent variables.
- [ ] I choose and label a sensible graph scale.

## 2. Slope

- [ ] I calculate slope from two points.
- [ ] I keep the subtraction order consistent.
- [ ] I recognize positive, negative, zero, and undefined slopes.
- [ ] I explain slope as a rate of change with units when needed.
- [ ] I solve a missing-coordinate slope question.

## 3. Equation of a line

- [ ] I identify `m` and `b` in `y = mx + b`.
- [ ] I graph a line using the y-intercept and slope.
- [ ] I write an equation from a graph.
- [ ] I write an equation from a slope and one point.
- [ ] I write an equation from two points.
- [ ] I check a point by substituting its coordinates.

## 4. Types of lines and intercepts

- [ ] I recognize `y = c` as horizontal with slope 0.
- [ ] I recognize `x = c` as vertical with undefined slope.
- [ ] I find an x-intercept by setting `y = 0`.
- [ ] I find a y-intercept by setting `x = 0`.
- [ ] I identify parallel lines by equal slopes.
- [ ] I find a perpendicular slope using a negative reciprocal.
- [ ] I write the equation of a parallel or perpendicular line through a point.

## 5. Systems of equations

- [ ] I explain why the intersection is the solution.
- [ ] I solve a system by graphing.
- [ ] I solve a system by comparison/substitution.
- [ ] I solve a system by elimination.
- [ ] I multiply every term when preparing an equation for elimination.
- [ ] I solve for both variables and write `(x, y)`.
- [ ] I check the answer in both original equations.
- [ ] I turn a simple word problem into two equations.

## Recognition speed round

Say the first move aloud:

| Prompt | First move |
|---|---|
| Two points; find steepness | Use the slope formula |
| Graph `y = −2x + 3` | Plot `(0, 3)`, then use slope `−2/1` |
| Find the x-intercept | Set `y = 0` |
| Line parallel to `y = 4x − 1` | Use slope `4` |
| Line perpendicular to slope `2/5` | Use slope `−5/2` |
| Both equations equal `y` | Compare the other sides |
| Opposite y-coefficients | Add to eliminate y |

## Five-question readiness check

Try these without notes.

1. Find the slope through `(−2, 1)` and `(4, 10)`.
2. Write the equation of the line with slope `−2` through `(3, 1)`.
3. Find both intercepts of `3x + 2y = 12`.
4. Write the slope of a line perpendicular to `m = 4/7`.
5. Solve `y = x + 5` and `y = −2x − 1`.

<details>
<summary>Answers</summary>

1. `m = (10 − 1)/(4 − (−2)) = 9/6 = 3/2`.
2. `1 = −2(3) + b`, so `b = 7`; `y = −2x + 7`.
3. x-intercept: `(4, 0)`; y-intercept: `(0, 6)`.
4. `−7/4`.
5. `x + 5 = −2x − 1`, so `x = −2`; then `y = 3`. Solution: `(−2, 3)`.

</details>

## Readiness result

- **5 correct:** Ready. Review mistakes once, then rest.
- **3–4 correct:** Nearly ready. Revisit the matching concept pages.
- **0–2 correct:** Work through the five pages in order and retry tomorrow.

## Exam habits

- [ ] I show substitutions and algebra steps for method marks.
- [ ] I label graphs and use a ruler for straight lines.
- [ ] I write coordinates and units in my final answer.
- [ ] I estimate whether the sign and size of my answer make sense.
- [ ] I leave time to check negative signs.
