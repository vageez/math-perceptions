> **Question:** How do I read and plot points?

## Think of a street map

The origin is your starting point. The x-coordinate moves you left or right; the y-coordinate moves you up or down.

<CoordinatePlane start={[-3, 2]} label="P" />

**Drag the point.** Watch the coordinates and the quadrant change as it moves.

## Worked example

**Plot the point $A(4,\ -3)$ and name the quadrant it lies in.**

1. Start at the origin, $(0,\ 0)$.
2. The x-coordinate is $4$, so move **4 units right** — a positive x goes right.
3. The y-coordinate is $-3$, so move **3 units down** — a negative y goes down.
4. Mark the point and label it $A$.
5. It now sits right of the y-axis and below the x-axis — the bottom-right region.

**Answer:** $A(4,\ -3)$ is in **Quadrant IV**.

## The one rule to remember

`(x, y)` means **across first, then up or down**.

- Positive `x` → right
- Negative `x` → left
- Positive `y` → up
- Negative `y` → down

## Formal meaning

A **Cartesian plane** is formed by a horizontal x-axis and a vertical y-axis. A point is named by an **ordered pair** `(x, y)`.

## Vocabulary points to the picture

| Word | What it points to |
|---|---|
| Cartesian plane | The entire coordinate grid |
| x-axis | Horizontal number line |
| y-axis | Vertical number line |
| origin | Centre point `(0, 0)` |
| ordered pair | The address `(x, y)` of a point |
| quadrant | One of the four regions |
| independent variable | The input; normally on the x-axis |
| dependent variable | The result that changes; normally on the y-axis |

## Plot a point

Plot `P(−3, 2)`:

1. Start at `(0, 0)`.
2. Move 3 units left because `x = −3`.
3. Move 2 units up because `y = 2`.
4. Mark and label the point. It is in Quadrant II.

## Read a point

If a point is 5 units right and 4 units down from the origin, its coordinates are:

`(5, −4)` — not `(−4, 5)`.

## Special locations

| Coordinate clue | Location |
|---|---|
| `x = 0` | On the y-axis |
| `y = 0` | On the x-axis |
| `x = 0` and `y = 0` | At the origin |

Points on an axis are **not** inside a quadrant.

## Tables become points

Each row stays together:

| x | y | Point |
|---:|---:|---|
| −2 | 4 | `(−2, 4)` |
| 0 | 1 | `(0, 1)` |
| 3 | −2 | `(3, −2)` |

Do not take `x` from one row and `y` from another.

## Independent or dependent?

> Ask: **What is allowed to change first? What responds?**

Example: Pay changes with hours worked.

- Hours worked = independent variable = x-axis
- Pay earned = dependent variable = y-axis

## More worked examples

### Example 2 — From a description to coordinates

**A point lies 5 units left of the y-axis and 2 units above the x-axis. Write its coordinates and name its quadrant.**

1. "Left of the y-axis" means x is negative, so $x = -5$.
2. "Above the x-axis" means y is positive, so $y = 2$.
3. Write across first, then up: $(-5,\ 2)$.
4. A negative x with a positive y is the top-left region.

**Answer:** $(-5,\ 2)$, in **Quadrant II**.

### Example 3 — A point on an axis

**A taxi charges a flat 3 dollars plus a fee for each kilometre. The first row of its table is 0 km and 3 dollars. Which variable belongs on the x-axis, and where does that row's point sit?**

1. Ask what changes first. The distance driven is chosen first, so distance is the **independent** variable — it goes on the x-axis.
2. The fare responds to the distance, so fare is the **dependent** variable — it goes on the y-axis.
3. The row gives a distance of $0$ and a fare of $3$, so the point is $(0,\ 3)$.
4. Because $x = 0$, the point lies **on the y-axis**.
5. A point on an axis is not inside any quadrant — this is where marks are lost.

**Answer:** Distance goes on the x-axis. The point $(0,\ 3)$ lies **on the y-axis**, not in a quadrant.

## When you see… think…

| When you see… | Think… |
|---|---|
| An ordered pair | Across with x, then vertical with y |
| A table of values | Every row is one point |
| A real situation | Input on x; result on y |
| `x = 0` or `y = 0` | The point lies on an axis |

## Common exam mistakes

- Swapping x and y.
- Moving vertically before horizontally.
- Ignoring a negative sign.
- Calling a point on an axis part of a quadrant.
- Using uneven scale intervals or forgetting axis units.

## Quick check

1. Which quadrant contains `(−4, −6)`?
2. Where is `(0, 7)`?
3. A taxi fare depends on distance travelled. Which variable goes on the x-axis?

<details>
<summary>Answers</summary>

**1. Quadrant of $(-4,\ -6)$**

1. $x = -4$ is negative, so the point is left of the y-axis.
2. $y = -6$ is negative, so the point is below the x-axis.
3. Left and below is the bottom-left region.

**Answer:** Quadrant III.

**2. Location of $(0,\ 7)$**

1. $x = 0$, so the point sits on the y-axis.
2. $y = 7$ is positive, so it is 7 units above the origin.
3. A point on an axis is not inside a quadrant.

**Answer:** On the y-axis.

**3. Which variable goes on the x-axis**

1. Ask which quantity changes first — the distance driven.
2. Distance is the independent variable, and the independent variable goes on the x-axis.
3. The fare depends on the distance, so fare goes on the y-axis.

**Answer:** Distance travelled.
