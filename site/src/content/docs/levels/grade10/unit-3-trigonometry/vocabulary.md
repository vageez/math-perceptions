> **Plain language first. Point to the triangle whenever possible.**

| Term | Plain-language meaning | Formal meaning / clue |
|---|---|---|
| acute angle | An angle smaller than a square corner | Between `0°` and `90°` |
| adjacent side | The leg beside the reference angle | Touches `θ` but is not the hypotenuse |
| ambiguous case | A Sine Law setup that may create two triangles | Can occur with SSA information |
| area | Space inside a shape | Measured in square units |
| degree | A unit for measuring an angle | Written with `°` |
| Heron’s Formula | Finds area from three side lengths | Uses the semiperimeter `s` |
| hypotenuse | Longest side of a right triangle | Opposite the `90°` angle |
| included angle | The angle held between two named sides | The “pinched” angle in SAS |
| inverse trig | Turns a side ratio back into an angle | `sin⁻¹`, `cos⁻¹`, or `tan⁻¹` |
| leg | One of the two sides that form the right angle | The non-hypotenuse sides |
| non-right triangle | A triangle without a `90°` angle | May require Sine Law or an area formula |
| opposite pair | A side and the angle directly across from it | Example: side `a` and angle `A` |
| opposite side | The side across from the reference angle | `O` in SOH CAH TOA |
| Pythagorean Theorem | Connects the three sides of a right triangle | $a^2+b^2=c^2$ |
| reference angle | The non-right angle used to label O and A | Usually written `θ` |
| right angle | A square corner | Exactly `90°` |
| right triangle | A triangle containing one right angle | Allows Pythagoras and SOH CAH TOA |
| SAS | Side–Angle–Side information | The angle lies between the two sides |
| semiperimeter | Half the distance around a triangle | $s=(a+b+c)/2$ |
| sine | Opposite divided by hypotenuse in a right triangle | `sin θ = O/H` |
| Sine Law | Connects side–opposite-angle pairs | $a/\sin A=b/\sin B=c/\sin C$ |
| SOH CAH TOA | A memory aid for three right-triangle ratios | Sine, cosine, and tangent |
| square root | The number that multiplies by itself to make a value | Undoes a square |
| tangent | Opposite divided by adjacent | `tan θ = O/A` |
| triangle inequality | Test that three sides can close into a triangle | Any two sides must add to more than the third |
| trigonometric ratio | A comparison of two side lengths | Sine, cosine, or tangent |

## Symbol decoder

| Symbol | Read it as |
|---|---|
| `θ` | the reference angle “theta” |
| `a ↔ A` | side `a` is opposite angle `A` |
| `O`, `A`, `H` | opposite, adjacent, hypotenuse |
| `s` | semiperimeter |
| `sin⁻¹` | inverse sine; returns an angle |
| `cm²` | square centimetres; an area unit |
